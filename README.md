# 🛡️ SAFETY & REGISTRY BACKUP

Windows Registry modifications can cause system instability or prevent applications from working correctly.

Before applying changes:

1. Create a system restore point.
2. Export the specific registry keys being modified.
3. Review every `.reg` file before importing it.
4. Avoid unverified performance tweaks and disabling security protections.
5. Test changes individually and keep a rollback plan.

Registry tweaks do not guarantee increased FPS or reduced latency.
